# OBSIDIAN-X

**OBSIDIAN-X** is a high-performance, minimalist e-commerce platform engineered with **Next.js**, **Go Fiber**, and **PostgreSQL**. It delivers a seamless shopping experience complemented by an integrated vendor dashboard for real-time product publishing and dynamic inventory management.

## Technical Highlights

* **Instant Search Architecture:** Features a real-time debounce search filter with automated dropdown suggestions and direct item routing.
* **Dynamic Review Engine:** Automated backend calculation of user ratings and reviews that instantly updates frontend state without requiring full page reloads.
* **Vendor Self-Service Pipeline:** Streamlined product publishing system enabling users to configure pricing, badges, and image galleries directly from their account dashboard.
* **Monochrome UI System:** Built with custom CSS modules providing a clean, distraction-free interface optimized for high responsiveness.

## Technical Specifications

* **Frontend Architecture:** Next.js App Router, React, TypeScript, Tailwind CSS, Lucide Icons
* **Backend Core:** Go (Golang), Fiber Framework, REST API routing, CORS configuration
* **Data Management:** GORM ORM, PostgreSQL database with cascade relationship deletion
* **Asset Handling:** Static logo and icon integration via Next.js metadata and custom public directory mappings
