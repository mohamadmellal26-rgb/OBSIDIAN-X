## 🚀 About The Project

**OBSIDIAN-X** is a feature-rich, full-stack e-commerce web application inspired by clean, monochrome aesthetics and high-end tech engineering. It provides a seamless shopping experience coupled with a robust vendor dashboard allowing users to instantly list, manage, and sell their own products.

---

## ✨ Key Features

* **Advanced Search & Instant Filtering:** Real-time product search with dynamic dropdown suggestions and direct navigation.
* **Vendor Self-Service ("Sell Your Product"):** Allows users to publish items directly to the public store interface with custom pricing, badges, and imagery.
* **Interactive User Dashboard:** Complete control over orders, designed products, and account settings.
* **Monochrome UI/UX Design:** Clean, distraction-free aesthetic with high responsiveness across all devices.
* **Secure Cart & Wishlist Management:** Fully synchronized state for shopping lists and quick checkout flows.

---

## 🛠️ Built With

This project leverages a modern, industry-standard tech stack:

* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
* **Backend:** Java Spring Boot (`REST API`)
* **Styling:** Custom CSS modules with a monochrome design system
